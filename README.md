## Deployment

This project is intended for GitHub Pages deployment. For a repository site, set the Vite `base` path to the repository name so assets resolve correctly on GitHub Pages [web:8].

### GitHub Pages setup

1. Go to **Settings → Pages** in the repository.
2. Set **Source** to **GitHub Actions**.
3. Add a workflow in `.github/workflows/deploy.yml`.
4. Ensure the build output directory is `dist`.
